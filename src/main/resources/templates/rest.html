REST API

A Mozi nyilvántartó alkalmazás REST API végpontjainak áttekintése.

REST API végpontok

A Mozi nyilvántartó alkalmazás REST API-ja lehetővé teszi a filmek, mozik és előadások adatainak lekérdezését JSON formátumban.

Az API Spring Boot és Spring Data JPA segítségével készült, az adatokat MariaDB adatbázisból olvassa ki.

Elérhető API-k

Metódus Végpont Leírás Megnyitás
GET /api/filmek Filmek listázása lapozással JSON megtekintése
GET /api/filmek/1 Egy film lekérdezése azonosító alapján JSON megtekintése
GET /api/mozik Mozik listázása lapozással JSON megtekintése
GET /api/mozik/1 Egy mozi lekérdezése azonosító alapján JSON megtekintése
GET /api/eloadasok Előadások listázása lapozással JSON megtekintése
GET /api/eloadasok/1 Egy előadás lekérdezése azonosító alapján JSON megtekintése

Lapozás használata

A listázó API-végpontok támogatják a lapozást a page és size paraméterekkel.

Például az első 5 előadás lekérdezése:

/api/eloadasok?page=0&size=5

A page=0 az első oldalt, a size=5 pedig az oldalanként megjelenített rekordok számát jelenti.
